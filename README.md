# HAK AUTO — premium website with a scroll-driven fly-through

A static site with no build step: plain HTML, CSS and JS.

```bash
python -m http.server 5173 --directory site
```

Then open http://localhost:5173. The style tile is at `/style-tile.html`.

URL switches for previewing the fly-through section:

| Switch | Shows |
| --- | --- |
| `?3d` | Real-time 3D fly-through of a stylised model of the premises (Three.js, no credits needed) — `site/js/flight3d.js` |
| `?mockup` | Animatic made from real HAK AUTO photos |
| `?static` | Reduced-motion version (chapters over stills) |
| `?shot=<beat-id>` | Jumps to a beat, e.g. `?3d&shot=atelier` |
| `?nointro` | Skips the branded intro (also skipped automatically for deep links like `#vehicules`) |
| `?lang=fr` / `nl` / `en` | Opens the site in that language (French is the default; the visitor's choice is remembered) |
| `?introat=<ms>` | Freezes the intro at a moment, e.g. `?introat=1600` (QA) |

| Edit this | File |
| --- | --- |
| Copy (FR/NL/EN), business facts, email, social links, services, rental, opening hours, fly-through beats, quotes | `site/js/content.js` |
| Interface labels in FR/NL/EN (buttons, forms, messages) | `site/js/i18n.js` |
| Styles for language switch, social, vehicle details, form channels, call button | `site/components.css` |
| Vehicle stock (snapshot of hakauto.be) | `python tools/refresh-stock.py` → `site/js/stock.js` |
| Design tokens and styles | `site/styles.css` (`:root`) |
| Fly-through frames and manifest | `site/media/flight/` (generated by `production/scripts/frames.py`) |

Footage production, prompts, status and the facts to verify are documented in `production/PRODUCTION.md`.

## Hosting (GitHub Pages)

Every push to `main` publishes the `site/` folder with `.github/workflows/pages.yml`.
One-time setup: repository **Settings → Pages → Source: GitHub Actions**.

The draft is kept out of search engines (`<meta name="robots" content="noindex, nofollow">` in `site/index.html` and `site/robots.txt`). Remove both at launch.

Raw production material (Higgsfield clips, stills, source photos, animatic working files) is deliberately not in the repository; see `.gitignore`.

After changing CSS or JS, bump the `?v=` value in `index.html`.
